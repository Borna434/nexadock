## NexaDock 0.6.0

### New
- **Own panels for the system icons.** Each icon opens a glass panel right above it:
  - **Network:** your connection (Ethernet speed and address), the Wi-Fi networks in range, Wi-Fi on and off, and joining a network with its password. Networks that need a sign-in open Windows' own list.
  - **Sound:** volume, the output device (speakers, headphones, monitor) in one click, and a mixer with every app that plays sound, each with its own volume and mute.
  - **Battery or power:** battery level and time left on laptops, and the Windows power mode (efficiency, balanced, performance). Desktops get a lightning icon for the power mode.
- **Game mode:** while a game or another app runs full screen and the bar steps aside, the widgets stop sampling the system (CPU, network, audio, logs, clock). NexaDock then costs the game nothing; everything catches up when you leave the game.

### Fixes
- The Claude widget's session now resets exactly five hours after your first message, as on Claude's usage page (it used to round up to the full hour).

### Note
Since Windows 11 24H2, Windows shows Wi-Fi names to apps only when they may use location. If the network panel asks for it, the button opens the right Settings page.

### Update
Installed copies offer this update in Settings › About (and through Pulse). Settings and data are kept.
