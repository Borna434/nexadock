## NexaDock 0.6.1

### Fixes
- **The bar steps aside for full-screen video in the browser.** Switching YouTube (or any web video) to full screen only resizes the browser window, so the bar used to stay on top. It now notices within a fraction of a second, and a borderless window that exactly fills the display counts as full screen even when Windows does not report it as such.

### Update
Installed copies offer this update in Settings › About (and through Pulse). Settings and data are kept.
