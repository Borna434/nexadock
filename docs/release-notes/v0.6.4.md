## NexaDock 0.6.4

### New
- **Drag to pin.** Drag a shortcut, program or folder from the desktop or File Explorer onto the bar and it is pinned. Drop it on a pinned app to place it right before that app.
- **Claude plan limits in percent.** The Claude widget now shows your 5-hour and weekly limit the way Claude itself reports them, on the bar (5h 6% · week 77%) and in the card with reset times. It uses the sign-in Claude Code keeps on this PC; without it the widget shows token counts as before.

### Update
Installed copies offer this update in Settings › About (and through Pulse). Settings and data are kept.
